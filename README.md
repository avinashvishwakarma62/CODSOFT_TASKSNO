# CODSOFT Python Programming Internship

This repository contains the Python programming tasks completed as part of my CodSoft internship.

The projects were developed as interactive desktop applications using Python and Tkinter, with a focus on practical implementation, user interaction, and basic GUI development.

## Tasks Completed

### Task 1 - To-Do List
A GUI-based To-Do List application that allows users to add, view, update, delete, and complete tasks through an interactive desktop window.

### Task 2 - Calculator
A GUI-based calculator that supports addition, subtraction, multiplication, division, percentage, decimal calculations, and keyboard input.

### Task 3 - Password Generator
A GUI-based password generator that allows users to generate strong passwords either based on a specific name or word, or completely randomly. It also supports custom password length and copying the generated password.

### Task 4 - Rock Paper Scissors
A GUI-based Rock Paper Scissors game where the user plays against the computer, with random computer choices, result detection, score tracking, and reset functionality.

### Task 5 - Contact Book
A GUI-based contact management application that allows users to add, view, search, update, and delete contacts including name, phone number, email, and address.
